# Flappy Bird (Android Clone)

Simple Flappy Bird clone written in Java for Android.

## Features
- Tap to make the bird jump
- Random pipes
- Score counting
- Game over & restart

## How to get the APK
1. Go to **Actions** tab
2. Select the latest **Build Flappy Bird APK** workflow run
3. Download the artifact **FlappyBird-debug**

Or trigger a new build by pushing to `main` or manually running the workflow.

## Build locally
Open the project in Android Studio and run.
